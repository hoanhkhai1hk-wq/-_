# 多智能体组织架构模板

一套实战跑通的多智能体分工模板：总指挥拆任务、Codex 做后端、WorkBuddy 做前端、
Harness 只做 Prompt 实验、用户当中转，GitHub 为唯一真相源。

## 文件

- `多智能体组织架构模板.md`：架构图、各角色职责、八条铁律、任务单 / 验收单 / 整改单模板。
- `chart.json`：同名机器可读版（角色、职责、铁律、验收清单）。

## 用法

1. 新项目直接套用本模板，只改项目名、仓库名和截止日期。
2. 总指挥发任务时按"任务单模板"填；验收时按"验收单模板"逐项核对。
3. 不合格开整改单，整改后复验；同一问题两次不过换实现方案。

## 铁律速览

- GitHub 是唯一真相源；逐单验收（对 commit 号、密钥扫描、逻辑核对、独立复现）。
- 密钥只放本地 `.env` 或 GitHub Secrets，禁进 Git / 前端 / 日志。
- 禁中文路径：目录、仓库名、包名全英文。
- 重要改动先看预览；每个项目定冻结日与提交物齐备日。
